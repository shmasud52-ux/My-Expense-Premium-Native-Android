# MyExpense — Premium Native Android

A native, offline-first personal finance app for Android.

## Stack
- Kotlin + Jetpack Compose
- Material 3
- Room database
- MVVM architecture
- Coroutines and Flow

## Performance goals
- Database and file work off the main thread
- Stable Compose state and lazy transaction lists
- Lightweight animations and no network dependency for core features
- Local data storage with backup/restore

## Build
Open this project in Android Studio, sync Gradle, then build the `app` debug APK. The project targets Android 8.0 (API 26) and newer.
